# Maryam OS

Maryam Yahaya's interactive product-design portfolio, presented as a playful pink desktop operating system.

## Run locally

You need Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The portfolio loads through `index.html` and redirects to `index-os.html`.

## Build

```bash
npm run build
```

The production build is written to `dist/`.

## Continue with Claude Code

Open this folder in Claude Code and ask it to read `CLAUDE.md` before making changes. That file explains the project structure, the live entry point, the visual rules, and the current design state.

The project images and resume live in `public/images/`. AI-build artwork lives in `images/ai-builds/`.
